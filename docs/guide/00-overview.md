# Codex 小白 60 天實戰路線

這份路線不是要你先背功能名，而是每天處理一個真實場景。

你可以把每一天都當成一支口播影片：先講「小白遇到什麼問題」，再給一段可以直接複製給 Codex 的問法，最後教他怎麼驗收結果。

::: tip 先記住一句話
第一次用 Codex，不要一開始就叫它「幫我優化」。先讓它只讀不改、先盤點、先說明風險，再決定要不要動手。
:::

![Codex 使用入口地圖](/images/codex-surfaces.svg)

## 怎麼使用這 60 天

每一天都照這個順序練：

1. 說清楚你現在手上有什麼。
2. 要求 Codex 先不要修改檔案。
3. 讓它盤點、分類、提出下一步。
4. 你確認方向後，再讓它小步執行。
5. 最後要求它交代改了什麼、怎麼驗證、還有什麼風險。
