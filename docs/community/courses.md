# Codex AI 工作與輕開發課

這門課給設計師、PM、內容工作者。重點不是把你訓練成工程師，而是讓你能用 Codex 處理日常工作，並完成低風險的輕開發任務。

你會學到怎麼整理資料、拆解需求、產出內容、檢查結果，也會練習改文案、調樣式、跑預覽、讀錯誤訊息。

## 適合誰

| 角色 | 你可能遇到的問題 | 課上會練什麼 |
| --- | --- | --- |
| 設計師 | 需求、截圖、設計稿說明散在不同地方 | 整理需求、產頁面文案、列出檢查清單、做簡單頁面修改 |
| PM | 會議紀錄、PRD、競品資料和任務拆解很花時間 | 把資料轉成任務、風險、待確認問題和交付清單 |
| 內容工作者 | 素材、筆記、PDF、腳本和簡報大綱整理太慢 | 把素材變成文章、腳本、簡報大綱和可複用 SOP |

## 直播線上課

**2 小時 Codex AI 工作入門。**

適合第一次想把 Codex 用進工作的人。課程會從一份真實資料或小任務開始，帶你完成一次可驗證的 AI 工作流程。

你會完成：

- 選一個適合 Codex 的低風險任務。
- 讓 Codex 先盤點資料，不急著改檔案。
- 把資料整理成摘要、表格、簡報大綱或任務清單。
- 學會要求 Codex 回報驗證方式。
- 理解什麼任務不該直接交給 AI。

**價格區間：早鳥 NT$990-1,980。**

## 線下陪跑小班

**半日 Codex 實戰陪跑，3-6 人。**

適合已經有資料、需求、素材、網站或小專案，想現場做出一套可重複流程的人。

你可以帶來：

- 一個要整理的資料夾。
- 一份 PRD、會議紀錄或競品資料。
- 一組課程筆記、PDF、截圖或內容素材。
- 一個想微調的簡單頁面或文件站。

現場會完成：

- 盤點你的資料和任務邊界。
- 選出一個可以當天完成的成果。
- 用 Codex 產出草稿、清單、表格、頁面修改或 SOP。
- 檢查結果是否可靠，留下之後可重複使用的提示詞或模板。

**價格區間：NT$4,000-8,000/人。**

## 不會承諾什麼

這不是大型系統開發課，也不是保證一次完成所有工作的代辦服務。

- 不直接處理敏感憑證、個資或生產環境。
- 不承諾複雜後端、正式資安審查或大型工程重構。
- 不把 AI 輸出當成免檢查的最終答案。

## 報名方式

掃 LINE/IG 詢問下一梯。請先簡單說明：

- 你的角色：設計師、PM、內容工作者，或其他工作類型。
- 想上直播課還是線下小班。
- 想處理的資料或任務。
- 希望上課的時間。
