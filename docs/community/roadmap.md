# 共建路線圖

目標：把這個倉庫做成面向全球初學者、創作者、開發者與團隊的 Codex 實踐知識庫。

## 第一階段：骨架完整

- [x] 建立 VuePress + Theme Hope 文件站。
- [x] 建立 README、貢獻指南、行為準則和安全政策。
- [x] 搭建入門、進階、團隊和案例目錄。
- [x] 新增官方資料索引。
- [ ] 補充第一批截圖和命令輸出。
- [ ] 給每篇教程增加“適用版本”和“最後核對日期”。

## 第二階段：指南成型

- [ ] 完成 CLI 從安裝到日常使用的完整教程。
- [ ] 完成 `AGENTS.md` 專題。
- [ ] 完成提示詞模板庫。
- [ ] 完成排障手冊第一版。
- [ ] 補齊 Cloud、IDE、桌面 App 的使用差異。

## 第三階段：案例驅動

- [ ] 收集 20 個真實工程案例。
- [ ] 每個案例包含任務說明、關鍵過程、驗證方式和覆盤。
- [ ] 建立案例標籤：前端、後端、測試、重構、文件、CI、安全。
- [ ] 補充失敗案例，說明 Codex 不適合直接處理的場景。

## 第四階段：社群傳播

- [ ] 設計更完整的首頁和 Open Graph 圖。
- [ ] 建立中英文關鍵詞索引。
- [ ] 釋出 GitHub Pages。
- [ ] 整理適合社媒傳播的短連結和學習路線圖。
- [ ] 邀請早期貢獻者認領章節。

## 貢獻入口

你可以從這些任務開始：

- 修正文件裡的不準確表述。
- 新增一個你親自跑過的 Codex 案例。
- 給排障手冊補一個常見錯誤。
- 把官方文件的新變化同步到資料索引。
